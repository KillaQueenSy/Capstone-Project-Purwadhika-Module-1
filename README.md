📚 Joestar Library
Joestar Library is a simple console-based Python application that allows users to view, add, update, delete, borrow, and return books. It's a great project for learning basic Python concepts like data structures, functions, conditionals, and input handling.

🛠️ Main Features
📖 View Books
Displays a list of available books (not currently borrowed) and allows searching for a book by name.

➕ Add Book
Adds a new book to the library. You can choose whether to allow or disallow duplicate book names.

✏️ Update Book
Updates the name of a book by its ID.

🗑️ Delete Book
Removes a book from the library by its ID.

📦 Borrow Book
Allows users to borrow a book by its ID. Borrowed books are not shown in the available list.

📥 Return Book
Allows users to return previously borrowed books.

🎵 Goodtime (Easter Egg)
Opens a surprise YouTube link for fun. 😄

🧠 How It Works
The application uses a dictionary to store books with IDs as keys and book names as values.

Borrowed books are tracked using a list.

The app prevents or allows duplicate book names based on user input.

A simple text-based menu guides the user through each function.
